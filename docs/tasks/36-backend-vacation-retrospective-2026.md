## 7. 방학이 남긴 작업 규약

코드보다 오래 갈 것들. 대부분 한 번 데인 뒤에 생겼다.

- **근거 없는 숫자를 코드에 안 박는다** — 검출기 풀 = `(mem_limit − RSS) / 98.7MB`, 탈퇴 가드 180초 = 세트 휴식, 로그인 제한 = 가정에서 유도. 한도도 설정도 없으면 기동 거부.
- **실패를 숫자로 바꾸지 않는다** — rig 가 실패·다른 실험을 결론으로 바꾸던 것을 세 번 잡았다(08-09). FAIL 행은 FAIL 로 남긴다.
- **팔당 1판이면 «팔» 과 «판 순서» 가 분리 안 된다** — 버림판 + 라틴 방격(또는 ABBA). 4차 초판이 이걸로 뒤집혔다.
- **값엔 조건을 단다** — 3.47배를 인용한 13곳에 조건을 달았고(08-13), 그 뒤로 정본 표는 조건 열을 뺄 수 없다.
- **문서 드리프트는 한 방향** — 기능 표는 맞고 «보장·관측·운영» 이 빠진다. 변경 후 판정은 파일 위치가 아니라 계약(RPC·전달 보장·proto 밖 계약·실패 처리·판정 기준).
- **무인 EC2 라운드** — bootstrap 은 커밋 SHA 로, `--instance-initiated-shutdown-behavior terminate`, 끝나면 스스로 내려감, 비용 트립와이어. 절대 처리량은 EC2 에서만.
- **트러블슈팅은 이슈로, 분기점은 decisions/ 로** — 결정 마크는 confirm 뒤에만.
