# 실제 촬영 검증 자료

## 지금 필요한 최소 촬영

우선 같은 사람이 스쿼트 영상 **2개**만 촬영한다. 첫 영상은 카메라를 정면에서 약 45도 옆에, 두 번째는 완전한 측면에 고정한다. 각 영상에서 처음 2초는 똑바로 서 있고, 스쿼트 5회를 평소 속도로 완전히 수행한 뒤 마지막 2초도 서 있는다. 두 영상 모두 사람이 직접 센 **완료 횟수**를 적는다. 이 두 각도를 비교하면 현재의 양쪽 다리 가시성 조건과 깊이 판정 문제를 구분할 수 있다.

카메라는 골반 높이 근처에 고정하고, 머리부터 신발까지 화면 안에 여유를 둔다. 랙·원판·다른 사람이 무릎이나 발목을 가리지 않게 한다. 원본 MP4를 유지하고 촬영 앞뒤를 자르지 않는다. 한 영상에 운동하는 사람 한 명만 들어오게 한다. 첫 두 영상으로 원인을 확인한 뒤 일반 속도와 느린 속도, 얕은 동작을 추가 촬영하면 된다. 전방 런지 검증용으로는 별도 영상에서 왼발 3회·오른발 3회를 완료하고 좌우 정답을 적는다.

파일을 `samples/validation/`에 넣고 파일명과 사람이 센 횟수만 알려줘도 된다. CSV 입력과 평가 실행은 내가 처리할 수 있다.

`labels.template.csv`를 `labels.csv`로 복사해 영상마다 한 줄씩 채운다. 개인을 식별할 수 있는 이름 대신 `p01`, `p02` 같은 임의 ID를 쓴다. 원본 MP4는 이 폴더에 놓고 `video`에는 파일명만 적는다. 영상과 `labels.csv`, 평가 결과 `results.csv`는 Git에서 제외된다.

| 열 | 입력 예시 | 설명 |
|---|---|---|
| `subject_id` | `p01` | 동일 촬영자를 묶는 임의 ID |
| `video` | `p01_lunge_01.mp4` | 이 CSV 기준 상대 경로 또는 절대 경로 |
| `exercise` | `squat`, `lunge` | 런지 항목 |
| `view` | `side`, `45deg`, `front` | 카메라 방향 기록. **런지는 반드시 `side`(완전 측면)** — 2026-09-22 검증에서 45도는 총 횟수는 맞아도 좌우(왼발/오른발) 라벨이 크게 틀렸다(`docs/decisions/lunge-repetition-counting.md` §3-6). 45도·정면 런지 촬영은 지원 범위 밖이라 평가하지 않는다. 스쿼트는 `45deg`도 정상 지원 |
| `mirrored` | `true`, `false` | 좌우 반전 저장 여부. 런지 좌우 비교에 필수 |
| `expected_total` | `10` | 사람이 센 **완료한** 동작 수 |
| `expected_left`, `expected_right` | `5`, `5` | 런지 참가자의 실제 왼발·오른발 기준 완료 횟수. 스쿼트는 비움 |
| `notes` | `7초에 가림` | 미완성 동작·가림·촬영 문제 등 |

한 줄 예시(실제 `labels.csv`에 입력):

```csv
p01,p01_squat_01.mp4,squat,45deg,false,5,,,촬영 끝에 2초 서 있기
p01,p01_lunge_01.mp4,lunge,side,false,10,5,5,앞발을 원위치로 되돌림
```

영상 시작과 마지막 완료 동작 뒤에 충분히 선 자세를 담고, 측면에서 적어도 한쪽 어깨·골반·무릎·발목·발이 이어서 보이게 촬영한다. 원본의 앞뒤를 자르지 않는다. 얼굴 등 개인정보가 있는 영상은 공유 범위를 먼저 정한다.

정답은 알고리즘 출력과 관계없이 사람이 영상을 보고 적는다. 스쿼트는 선 자세에서 내려갔다 다시 선 **완료 주기**를 센다. 런지는 한쪽 무릎이 충분히 굽혀졌다가(약 100도 이하) 다시 펴지는 주기를 앞발 쪽으로 나눠 센다 — 2026-09-22부터 발이 원래 위치로 돌아오는지는 더 이상 판정 기준이 아니라서, 워킹 런지(발이 원위치로 안 돌아오고 계속 전진)도 정상적으로 센다. 무릎을 끝까지 펴지 않고 반복(펄싱)해도 되지만, 반드시 완전 측면(`view=side`)에서 촬영한다 — 45도 등 다른 각도는 좌우 라벨을 신뢰할 수 없어 평가하지 않는다. 얕은 동작이나 끝내지 않은 동작은 `notes`에 시각과 함께 적어 별도로 검토한다.

```powershell
cd ai-server
$env:DEBUG='false'
.\.venv\Scripts\python.exe scripts\evaluate_dataset.py ..\samples\validation\labels.csv
```

기본은 앱과 같은 초당 3개 프레임을 분석하고 `results.csv`에 영상별 추적 가능 프레임, 횟수, 오차를 기록한다. 콘솔의 평균 절대 오차(MAE)와 **총횟수가 정확히 일치한 영상 수**는 정답이 있고 평가 유효한 영상만 계산한다. 평가 유효 조건에는 시작 자세 확인과 사용 가능한 프레임 비율 70% 이상이 포함된다. 70%는 연구 결과가 아니라 스쿼트 단일 영상 평가기와 맞춘 운영상 품질 기준이다. 평가가 유효하지 않은 영상의 `0회`를 정답으로 취급하지 않는다. 런지 좌우 오차의 자동 집계는 좌우 반전되지 않은 영상에 한정한다. 반전 영상의 좌우는 원본 방향을 확인한 뒤 별도로 해석한다.
